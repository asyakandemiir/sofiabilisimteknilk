# Sofia Bilişim Teknik Servis

Kurumsal teknik servis hizmetleri için geliştirilmiş profesyonel web arayüzü.

## Canlı Demo
Sitenin güncel halini buradan inceleyebilirsiniz: [www.sofiabilisimteknik.com](https://www.sofiabilisimteknik.com)

## Kullanılan Teknolojiler
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome

## Özellikler
- Mobil uyumlu tasarım.
- 4 aşamalı servis süreci anlatımı.
- WhatsApp ve telefon ile hızlı iletişim entegrasyonu.
- Kurumsal modern arayüz tasarımı.

## Hakkında
Bu proje, web geliştirme becerilerimi sergilemek ve kurumsal bir platform için çözüm sunmak amacıyla hazırlanmıştır.
